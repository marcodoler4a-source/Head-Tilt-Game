# Mushroom Kingdom classroom website

An interactive, mobile-friendly website created from the supplied 49-slide classroom PowerPoint.

## Run locally
Open `index.html` in a browser. All images are local and no installation is needed.

## Publish on Render
1. Upload **all files**, including the `slides` folder, to your GitHub repository.
2. Create a Render **Static Site** linked to that repository.
3. Leave Build Command empty and set Publish Directory to `.` (if files are at repository root).
4. Deploy and open your `.onrender.com` URL.

## Features
- All 49 original slide visuals preserved as images.
- Previous/Next navigation, keyboard arrows, fullscreen.
- Interactive Beach Rally word-order game based on the five sentence challenges in the PowerPoint.
- Three team score counters (session-only).

## Notes
The original PowerPoint's external `file:///C:/Users/.../index(2).html` links are local to its creator's computer and cannot work on a public website. This website replaces them with its own playable sentence game. PowerPoint animations and audio are not reproduced. Slide visuals are rendered as static images.
